Deploy to GitHub Pages in 3 Simple Steps

Follow these quick steps to get this website published for free on GitHub Pages:

  1. Step 1: Download & Extract the ZIP Archive
    Click the Download Website (.ZIP) button above to save IKTA_Smart_Dialer_Website_Pages.zip on your computer. Extract its contents into a folder.
  2. Step 2: Upload to a GitHub Repository
    Create a new repository on GitHub.com (e.g., smart-dialer-web). Commit and push all the extracted files (including index.html and the screenshots/ folder) directly to the main branch.
  3. Step 3: Enable GitHub Pages
    In your GitHub repository, open Settings → Pages. Under Build and deployment → Branch, select main and folder / (root), then click Save.
    Your website will be live in 60 seconds at: https://<your-username>.github.io/<repository-name>/
