Setting 1

Set as Default Phone App (Telecom Service)

Ensure IKTA Smart Dialer handles all incoming voice calls, full-screen incoming alerts, outgoing call placements, and heads-up notifications across Android 10, 11, 12, 13, 14, and 15+.

Configuration Guidelines:

  1. Open the application. When prompted, tap Set as Default Phone App.
  2. In the native Android system dialog, choose IKTA Smart Dialer and tap Set as Default.
  3. Grant the requested telephony, contact, and notification permissions to activate high-priority in-call services.
  4. If the system prompt does not show, navigate to Android Settings › Apps › Default Apps › Phone App and select IKTA Smart Dialer.
  • Android Telecom Framework: Replaces the slow stock OEM dialer with instant call-state response.
  • Full Screen & Heads-Up Alerts: Never miss a call even while playing games or watching fullscreen videos.
  • Dual-SIM Placement: Directly select SIM 1 or SIM 2 with zero extra confirmation pop-ups.
Setting 2

Account & Sync Management

Manage unified contact synchronization across your Google Accounts, device phone memory, and active SIM cards with automated real-time change detection.

Configuration Guidelines:

  1. Navigate to Settings › Account & Sync.
  2. Review all detected account sources (Google Accounts, Device Storage, SIM 1, SIM 2).
  3. Toggle individual accounts to include or exclude specific directories from your active dialer address book.
  4. Tap Sync Now to force an immediate background refresh of newly added contacts.
  • Multi-Account Aggregation: Merges Gmail work accounts, personal Google profiles, and device contacts seamlessly.
  • Background Delta Sync: Only syncs new or edited contacts to minimize CPU and battery drain.
  • Account Filtering: Easily isolate and view only business or personal contacts in one tap.
Setting 3

Calling Options & SIM Slot Routing

Customize your default outgoing call SIM preferences, configure auto-retry for dropped calls, and set up rapid 1-touch speed dial shortcuts.

Configuration Guidelines:

  1. Open Settings › Calling Options.
  2. Under Default Calling SIM, select Always Ask, SIM 1, or SIM 2.
  3. Enable Auto Redial on Busy to automatically re-attempt failed connections up to 3 times.
  4. Assign emergency and VIP family numbers to keys 2 through 9 for instant long-press dialing.
  • Intelligent Dual-SIM Engine: Automatically remembers which SIM was previously used to call each contact.
  • ViLTE Carrier Video Calling: Direct 1-tap HD video calling over operator 4G/5G networks.
  • Dial Pad Touch Tones: Customizable DTMF audio feedback during number key presses.
Setting 4

Ringtone & Vibration Customization

Set separate ringtones and haptic vibration cadences for SIM 1 and SIM 2 so you instantly know which line is ringing without looking at the screen.

Configuration Guidelines:

  1. Tap Settings › Ringtone & Vibration.
  2. Select SIM 1 Ringtone to assign a ring melody from device storage or system sounds.
  3. Select SIM 2 Ringtone for your second line (e.g. personal vs business).
  4. Enable Vibrate on Call Connected to receive a subtle haptic confirmation when the callee answers.
  • Independent SIM Audio: Distinct audio profiles for work and personal numbers.
  • Ascending Ringtone: Starts softly and gradually increases volume to prevent sudden loud startles.
  • Gentle Connection Haptics: Know precisely when the remote party answers without holding phone to your ear.

Default Country Code & International Dialing

Ensure numbers saved in your address book without international prefixes (+91, +1, +44) format and connect effortlessly. Includes a custom prefix editor and a directory of 240+ global nations.

Configuration Guidelines:

  1. Open Settings › Default Country Code in the application.
  2. View the How Country Code Formatting Works guidance explainer.
  3. Use the Custom Country Code field to input any custom prefix and tap Save.
  4. Alternatively, scroll through the Popular Country Codes directory (India 🇮🇳, USA 🇺🇸, UK 🇬🇧, Australia 🇦🇺, Bangladesh 🇧🇩, etc.) and tap to set as active default.
  • E.164 Automated Normalization: Strips national trunks ('0') and matches caller ID records seamlessly.
  • Custom Prefix Input Box: Type any ITU prefix (+1 to +999) with real-time preference persistence.
  • 240+ Global Nations Directory: High-resolution emoji flags, localized dialer codes, and instant tap-to-activate.

Setting 6

Picture Sync & High-Resolution Contact Avatars

Synchronize crisp, full-screen contact photos across all connected accounts. Keeps your dialer, in-call screen, and contact profile cards visually rich and modern.

Configuration Guidelines:

  1. Navigate to Settings › Picture Sync in the application.
  2. Select Sync Contact Photos to pull high-res avatars from Google Contacts and cloud profiles.
  3. Choose Wi-Fi Only Sync to preserve mobile cellular data when fetching large album pictures.
  4. Use Clear Cached Photos anytime you want to force fresh image re-download.
  • High-Definition In-Call Photos: Displays crystal-clear caller images on incoming calls.
  • Intelligent Thumbnail Caching: Zero lag or stuttering when scrolling through 5,000+ contacts.
  • Bandwidth Optimization: Compresses images locally in WebP format for fast render speeds.

Remove Duplicate Contacts & Address Book Cleaner

Clean clutter and eliminate messy duplicate records across multiple email accounts, SIM cards, and phone storage. Features dual-tab scanning for duplicate numbers and phonetic name merging.

Configuration Guidelines:

  1. Tap Settings › Remove Duplicate Contacts to launch the scanner.
  2. Tab 1: Duplicate Numbers scans for identical phone numbers on multiple contact cards.
  3. Tab 2: Duplicate Names groups overlapping contact entries (e.g. *121# with Instanthelp 24x7 vs my airtel).
  4. Select which display name to keep using interactive radio buttons and tap Save All to merge safely.
  • Dual-Tab Scanner Architecture: Separate tabs for Duplicate Numbers (0) and Duplicate Names (1).
  • Interactive Conflict Resolver: Radio buttons let you choose the primary name across Google and SIM accounts.
  • Zero Data Loss Guarantee: Merges multiple secondary numbers, emails, and notes into one unified profile.

Call Blocker & Blocked Numbers Manager

Silence harassment, unwanted telemarketers, and private numbers with robust Telecom-layer call rejection. Manage your blacklist via Type Number, Select Contact, or 1-tap Recent Calls blocking.

Configuration Guidelines:

  1. Open Settings › Call Blocker to view your active blacklist manager.
  2. Toggle Block calls from unidentified callers to auto-reject incoming calls with no identified caller name.
  3. Use action buttons: Type Number, Contact, or History to add numbers to your blocklist.
  4. Alternatively, tap Block directly on any Recent Call card to trigger the instant Block Confirmation Dialog.
  • Unidentified Caller Rejection: Instantly drops callers who mask their identity.
  • 3-Way Addition Hub: Direct keypad manual entry, address book picker, or call log import.
  • 1-Tap Home Screen Blocking: Block nuisance callers directly from recent logs without opening settings.
